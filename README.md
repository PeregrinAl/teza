# teza

Веб-платформа критического анализа дискуссий: редактируемая карта утверждений,
аргументов и доказательств с прослеживаемостью до исходного текста.

## Роль этого репозитория

`teza` — обложка проекта и место для общей спецификации, архитектурных решений
и договорённостей между компонентами. Интерфейс и backend развиваются отдельно.

## Ориентир первого релиза

Создать вопрос → вставить дискуссию → получить явно обозначенную AI-разметку
или демонстрационный mock-результат → исправить тезисы и аргументы → построить
карту → добавить источники и аннотации ошибок → сохранить, повторно открыть
и экспортировать анализ в JSON и Markdown.

teza — публичный ресурс для изучения аргументов и дискуссий.
Внешние обсуждения служат материалом для базы знаний: содержательные аргументы
обезличиваются и переформулируются, ошибки и особенности обсуждения описываются
отдельными маркерами. Профили участников и оригинальные комментарии
не публикуются. В дальнейшем возможен платный доступ к отдельным разборам.

Ручная работа и демонстрационный провайдер доступны без обязательного платного
LLM API. AI-компонент заменяем; подтверждённые данные от него не зависят.
